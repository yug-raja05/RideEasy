# RideEasy - Bike & Scooter Rental Website

A modern, fully responsive website for bike and scooter rentals with stunning 3D effects powered by Three.js.

## Features

- **3 Pages**: Home, Bikes/Fleet, and Contact
- **Three.js Integration**: Beautiful 3D animations and effects throughout
- **Fully Responsive**: Works perfectly on all devices
- **Modern Design**: Neon blue/cyan theme with glowing effects
- **Interactive Elements**: Modals, carousels, filters, and more

## Color Scheme

- Background: #000000 (Black)
- Accent: #007BFF (Electric Blue)
- Text: #FFFFFF (White)
- Highlight: #00FFFF (Cyan Glow)

## Pages

### Home Page (index.html)
- Hero section with 3D particle effects
- How it works section
- Featured vehicles carousel
- Why RideEasy trust section
- Interactive map with pickup points
- Testimonials slider
- Footer with newsletter

### Bikes Page (bikes.html)
- Advanced filtering system
- Vehicle grid with detailed cards
- Vehicle detail modals with image galleries
- Quick reserve bar (mobile)
- Promo codes and loyalty program

### Contact Page (contact.html)
- About section with 3D bike animation
- Contact form with validation
- Live chat simulation
- Pickup points and opening hours
- FAQ accordion
- Interactive map

## Setup

1. Simply open `index.html` in a web browser
2. All files should be in the same directory
3. Internet connection required for:
   - Three.js library (CDN)
   - Font Awesome icons (CDN)
   - Unsplash images (for vehicle images)

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
